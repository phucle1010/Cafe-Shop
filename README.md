# Cafe-Shop
## Giới thiệu
Ứng dụng quản lý quán cafe giúp tối ưu hóa quy trình đặt món, thanh toán, và quản lý doanh thu. Hỗ trợ nhân viên theo dõi đơn hàng, quản lý thực đơn, và cập nhật thông tin món ăn nhanh chóng. Quản lý khách hàng hiệu quả với tính năng thẻ thành viên và chương trình khuyến mãi. Giao diện thân thiện, dễ sử dụng cho cả chủ quán và nhân viên.

## Công nghệ sử dụng
- C# (C-Sharp) là một ngôn ngữ lập trình hiện đại, hướng đối tượng, do Microsoft phát triển. Nó được thiết kế để phát triển các ứng dụng trên nền tảng .NET, bao gồm ứng dụng desktop, web, và di động. C# có cú pháp dễ đọc, mạnh mẽ, và hỗ trợ nhiều tính năng như lập trình bất đồng bộ, LINQ, và quản lý bộ nhớ tự động. Đây là ngôn ngữ phổ biến trong phát triển phần mềm doanh nghiệp và ứng dụng Windows.
- Sử dụng công nghệ WPF (Windows Presentation Foundation) là thế hệ kế tiếp của WinForm dùng lập trình các ứng dụng Windows phát triển trên nền tảng .NET 3.5 trở về sau. WPF mang đến cho việc lập trình trở nên đơn giản hơn từ thiết kế giao diện, xử lý dữ liệu (sử dụng Linq kết hợp với cơ chế Binding) giúp việc lập trình dễ dàng và mạnh mẽ hơn hẳn WinForm.
- SQL Server là hệ quản trị cơ sở dữ liệu quan hệ (RDBMS) của Microsoft, dùng để lưu trữ, quản lý và truy vấn dữ liệu. Nó hỗ trợ ngôn ngữ SQL, có tính năng bảo mật, sao lưu và phục hồi, và thường được sử dụng trong các ứng dụng doanh nghiệp. SQL Server tích hợp tốt với hệ sinh thái Microsoft như .NET và Azure.
